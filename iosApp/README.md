# iosApp — Rafiq iOS Target

This directory hosts the native Xcode / SwiftUI application wrapper for the Rafiq Kotlin Multiplatform (KMP) application.

## Architecture

- **`ComposeApp` framework**: Generated by `:composeApp:linkDebugFrameworkIosSimulatorArm64` or `:composeApp:linkReleaseFrameworkIosArm64`.
- **`MainViewController.kt`**: Bridges Compose Multiplatform UI (`RafiqAppRoot`) into UIKit's `UIViewController`.
- **`ContentView.swift`**: SwiftUI `UIViewControllerRepresentable` hosting `MainViewController()`.
- **`iOSApp.swift`**: SwiftUI App lifecycle entry point.

## Running on macOS

```bash
# 1. Build the KMP framework for iOS Simulator
./gradlew :composeApp:linkDebugFrameworkIosSimulatorArm64

# 2. Open Xcode or run via xcodebuild
open iosApp/iosApp.xcodeproj
```
